CSS3 伪元素实战技巧

本文属于《HTML 与 CSS》第 43/62 篇
上一篇系列目录下一篇

伪元素是 CSS 里最“魔”的一小块：不动 HTML，靠一条 content 就能在元素内容的开头或结尾造出一个虚拟盒子。清除浮动、气泡尾巴、章节自动编号这些习以为常的技巧，底层都是它。本文先把 ::before 与 ::after 的生成内容机制讲明白，再给七个项目里直接能用的实战写法，兼容基线定在 IE8，适合已经熟悉选择器语法、想把伪元素从“看得懂”用到“变得顺手”的读者。

伪元素：生成内容造出的虚拟盒子

伪元素不在文档树里。p:after { content: "完"; } 会在段落内容末尾追加一段“生成内容”（generated content），这段内容自己形成一个盒子：它继承宿元素的大部分样式，参与布局，可以设 position、background、transform，但永远不被 DOM 容纳。这就是它和普通元素的本质区别——HTML 里没有这个节点，DOM 接口摸不到它，它只存在于渲染层。

每个元素最多各有一个 :before 和 :after，它们挂在元素内容区的首尾，而不是外边距之外。另外一族伪元素 ::first-line 与 ::first-letter 语义不同，是“选取已存在的文字”而非“造新盒子”，IE 与 Chrome、Firefox 都支持已久，且只接受字体、颜色、背景、缩进这类文本相关属性；私有实现的 ::selection 则只有 color 与 background-color 两项可靠，Firefox 只认 ::-moz-selection 的私有写法，必须与标准选择器拆成两条独立规则；IE 侧要到 IE9 才有支持。本文的主角仍是 :before 与 :after。

双冒号是 CSS3 引入的区分：伪类描述状态、保持单冒号，伪元素生成盒子、改用双冒号。真实的兼容约束是：IE8 只认单冒号的 :before，双冒号会被它当作未知选择器；IE9 及以上两种都认。

content 能放什么：空串是入场券

content 是伪元素上决定“盒子是否存在”的唯一开关，取值有六类：

空串与 none 的区别必须掰清楚：content: none 表示这个伪元素不存在，后面写的 width、background、position 全部落空；content: "" 会生成一个空盒子，样式才有依附的对象。三角形、下划线、角标这类纯几何技巧，全部从 content: "" 起步。伪元素默认是行内盒子，想摆尺寸记得先 display: block 或配合绝对定位。

url() 生成的是一张替换元素内容，尺寸跟随图片原始大小，给伪元素本身设宽高管不到里面的图；图片加载失败时多数浏览器什么都不显示，也不提供任何替代文本的出口，所以纯装饰可以用，承载信息不行。

attr() 要划清 2014 年的边界：它只取属性的字符串值，属性不存在时按空串处理。CSS3 Values Level 3 草案里还有 attr(data-w length, 10px) 这种把属性值当类型值用的设想，截至本文写作时没有任何浏览器实现，不要用 attr() 给伪元素传尺寸或颜色，这是幻想功能。

为什么用伪元素而不是在容器末尾补一个 <div class="clear"></div>？三个理由：第一，不污染 HTML，结构文件里不会躺着一排语义为零的空标签；第二，一个 class 在任何容器上复用，不必每处手写额外节点；第三，前后各挂一个生成盒子恰好围住浮动子元素，配合 display: table 还顺手解决了早期 block 版本首尾 margin 与父元素合并的问题。代价是这个盒子只存在于渲染层，若哪天需要 JS 在容器末尾插入真实节点，别指望能找到那个“看不见的分隔符”。

气泡尾巴：把三角形挂到伪元素上

用四边框拼三角形的原理，《CSS实现箭头、三角与对话框气泡》一文已经推导得很完整，本文只讲“挂”的这层：怎么把它安排到伪元素上，让 HTML 一个字符都不多。

:before 与 :after 两个配额正好充当外、内两层三角，这是伪元素配额最舒服的一种用法。挂的时候有三件事要注意：宿元素要 position: relative，否则尾巴会定位到别的祖先上去；祖先一旦 overflow: hidden，探出边界的三角会被直接裁掉；气泡宽度是百分比时，尾巴的 left 用百分比或配合 min-width，不然窄屏下会跑出去。

这些坑一定会踩

第一个坑：JavaScript 选不到伪元素。document.querySelectorAll("p:after") 只会报选择符非法或返回空，因为它根本不在文档树里。读取样式只有一条路：window.getComputedStyle(el, ":after") 的第二个参数接受伪元素标记，能拿到它的计算值——注意 IE8 连 getComputedStyle 本体都没有，老 IE 的尺寸读取另见《DOM 样式操作与 getComputedStyle》。写入则完全不存在：伪元素没有 style 对象，想改内容只能改宿元素的 class 或 data- 属性值，让样式规则间接生效。

第二个坑：伪元素拿不到几何信息。它没有 offsetWidth、没有 getBoundingClientRect，2014 年的所有浏览器都如此，因为这套 API 全部挂在元素对象上。需要精确测量一个由伪元素画的形状，只能从 getComputedStyle 逐条读宽高字符串自己拼，或者干脆换真实节点。

第三个坑：可访问性与复制。前面反复提过，content 文本对读屏不可靠，url() 图片没有 alt 的出口；另外用鼠标选中文本时，生成内容在有的浏览器里能选中能复制，在有的里面直接被跳过，打印时同理。编号、引号这类“看了就行”的内容无妨，指望用户复制走的文字请放 DOM。

第四个坑：配额、层叠与裁切。:before 与 :after 每元素各只有一个，用完后只能上真实节点；伪元素不能再套伪元素，:before:after 这种链条是无效语法。伪元素的盒子是宿元素的子盒子：父级 overflow: hidden 会裁掉绝对定位的尾巴；把伪元素 z-index 设为 -1，在宿元素不形成层叠上下文时会垫到宿元素背景之下——这是做装饰底纹的常用招，也是“为什么我的角标不见了”的头号事故源。

小结：伪元素与真实 DOM 的判断表

需求 用什么 理由
清除浮动、装饰几何图形 伪元素 零结构成本，样式状态机驱动
编号、引号、角标等辅助标记 伪元素 自动维护，不脏 HTML
应被搜索、被朗读的正文 真实 DOM 爬虫与读屏只认 DOM
需要 JS 选中、测量、操作 真实 DOM 伪元素没有 API 入口
需要 alt、title、事件语义 真实 DOM 伪元素带不了属性
每元素两个配额已用尽 真实 DOM 无法嵌套，无法追加

机制层面本文只讲了一件事：伪元素是 content 开关控制的一个渲染层盒子，盒子存在与否、存在成什么样，全看这一条声明。实战层面给出的七个技巧共享同一个判断标准——内容是装饰、冗余、可自动推导的，交给伪元素；信息唯一、要被选中、测量、朗读的，留在 DOM。往前看两句：CSS 自定义属性、原生 dialog 配套的 ::backdrop、组件化的 ::part 在 2014 年 9 月还都是草案或极早期实现，本文所有代码都不依赖它们；拿 IE8 当底线写单冒号，把生成内容当渲染层的状态机用，就是当下最划算的用法。
