Vim 基础操作与配置

本文从一次 ssh 上去改配置的尴尬经历讲起，把 Vim 的模式、移动、编辑、搜索、寄存器与宏、替换、配置和插件梳理一遍。适合刚在服务器上被迫使用 vi 的开发者，读完之后至少能做到不慌、能改、能退出来。

从一次 ssh 改配置说起

周五下午，测试环境的 Nginx 配置被改坏，页面直接 502。我 ssh 到服务器，sudo vi /etc/nginx/nginx.conf，用方向键挪到报错的那一行，敲了几个字符发现屏幕没有反应，才想起要先按 i。改完想保存退出，按了 Esc 又不知道该输入什么，手指在键盘上乱按一通，最后 Ctrl-Z 把进程挂到后台，以为已经退出，其实终端还被占着。

这类事故的根源不是命令记不住，而是没有建立“模式”的概念。Vim 继承自 vi，2017 年主流发行版自带的是 Vim 7.4，Vim 8.0 在 2016 年 9 月发布，新装的系统上已经能见到。服务器上敲 vi，打开的通常就是 Vim。它和记事本最大的差别在于：同一个按键在不同模式下含义完全不同，i 在普通模式下是“进入插入模式”，在插入模式下就是一个字母 i。

Vim 有四种常用模式。

  • 普通模式：打开文件后的默认状态，移动、删除、复制都在这里完成。
  • 插入模式：按 i、a、o 等进入，这时打字才是打字，Esc 返回普通模式。
  • 可视模式：按 v 进入，先选中一段文本，再对选区执行命令。
  • 命令行模式：普通模式下按 :，光标跳到屏幕底部，输入保存、替换一类的命令。

判断自己在哪个模式，最直接的办法是看屏幕右下角。插入模式会显示 -- INSERT --，可视模式显示 -- VISUAL --，块选择显示 -- VISUAL BLOCK --，命令行模式则是一个冒号加闪烁的光标。刚开始练 Vim 时，每次按键前瞄一眼右下角，比背十条快捷键有用。

移动光标：先把位置找对

普通模式下不该去碰方向键。h、j、k、l 分别对应左、下、上、右，手指停在主键区，移动时不用把手挪到角落。刚开始会觉得别扭，一周之后就会形成肌肉记忆。

按词移动比按字符快：w 到下一个词首，b 回到上一个词首，e 到当前词的词尾。行内定位用 0 到行首、^ 到第一个非空白字符、$ 到行尾。0 和 ^ 的区别在缩进代码里很明显，^ 会跳过行首的空白，直接停在第一个字符上。

跨行跳转靠 gg 和 G：gg 到文件第一行，G 到最后一行，42G 跳到第 42 行。行号也可以用命令行模式，:42 回车效果相同，要到末行则写 :$。

段落之间用 { 和 } 跳，一次越过一个空行块。改 Nginx 的 server 配置时，一个块接一个块地看，比一行行滚要清楚。% 在配对的括号之间来回跳，从 { 跳到 }，再按一次跳回来，检查嵌套层级很顺手。

以上命令都可以带数字前缀：3w 前进三个词，5j 下移五行，2} 越过两个段落。Vim 里“次数 + 命令”是通用语法，后面的删除、复制同样适用。

编辑：把操作当成动词加动作

进入插入模式有六个入口，区别值得记清：i 在光标前插入，a 在光标后插入，I 跳到行首第一个非空白字符前插入，A 跳到行尾插入，o 在当前行下方新开一行，O 在上方新开一行。改配置时最常用的是 A 和 o：前者补一个分号，后者加一整行。

删除与复制：x 删一个字符，dd 删整行，yy 复制整行，p 粘贴到光标之后。dd 之后用 p 可以把它粘到别处，相当于剪切。cc 删除整行并进入插入模式，等于“重写这一行”；s 删掉光标下的字符并进入插入模式，适合只改一个字符的场景。

Vim 的编辑命令遵循“动词 + 动作”的语法。d 表示删除，后面接一个范围：dw 删到下一个词首，d$ 删到行尾，d0 删到行首，dd 是整行的特例。diw 删掉光标所在的一个词，中间的 i 表示 inner，只处理词本身；daw 会连词后面的空格一起删。c 是同一个语法，cw 改一个词，ci" 改一对引号里的内容。这种组合数量有限、可以推导，不用为每种情况背一条命令。改配置里的一个值，ciw 比先删再补更稳。

. 重复上一次修改，是 Vim 效率的来源。它重放的是一整套改动，包括动作范围和插入的文本。把若干行的 true 改成 false，可以先用 /true 找到第一处，ciw 输入 false，Esc，再按 n 跳到下一个匹配，按 . 重复。找到、改掉、跳下一个、点一下，节奏非常稳定。

撤销用 u，重做用 Ctrl-r。Vim 的撤销是树状的，可以退回分支再走另一条路，日常记住这两个就够。

搜索用 /关键词 向下、?关键词 向上，回车后 n 找同方向下一个，N 找反方向。光标停在某个词上按 *，直接以这个词为目标搜索，省去输入。:set hlsearch 打开全部匹配的高亮，:nohlsearch 临时关掉。高亮常驻会干扰阅读，通常映射一个快捷键随时清除。

可视模式与列编辑

v 进入字符可视模式，V 进入行可视模式，Ctrl-v 进入块可视模式。选中之后按 d 删除、y 复制、> 右缩进、< 左缩进，也可以直接 c 改掉选区。> 在普通模式下要跟动作，>> 才是缩进当前行，在可视模式里对整段选区按一次就够。

块可视是 Vim 里被低估的功能。要把一段配置整体注释掉，用 Ctrl-v 选中这些行的第一列，按 I 输入 #，再按 Esc，所有被选中的行都会加上井号。反过来，选住行首的注释符号按 d，就能批量取消注释。对齐多行的等号、删除一列多余的空格，也是同样的操作。这个能力在 Vim 7.4 上已经完整可用，不需要插件。

gv 重新选中上一次的选区，改完发现漏了一行时很方便。

文件、缓冲区、窗口与标签页

:w 写入，:q 退出，:wq 保存并退出，普通模式下按 ZZ 等效。:q! 放弃修改强制退出，这一条最该先记住：改坏了不想保存，用它，而不是去按 Ctrl-Z 或者直接关终端。

:e 文件名 打开另一个文件。Vim 用缓冲区管理所有打开过的文件，:ls 列出，:bn、:bp 切到下一个、上一个，:b 3 直接跳到 3 号缓冲区。缓冲区是文件在内存里的副本，窗口只是它的一个视图，同一个缓冲区可以开在两个窗口里。

分屏用 :sp 水平切分、:vsp 垂直切分，Ctrl-w 加 h、j、k、l 在窗口之间移动。对照同一份配置的两段，或者一边看日志一边改配置，分屏比来回切换省事。标签页用 :tabnew 新建，gt、gT 前后切换。窗口适合“同时看”，标签页适合“分任务放”。

寄存器与宏

复制和删除都会写进寄存器。无名寄存器存最近一次操作，"0 存最近一次复制，"1 到 "9 存删除历史。用 "ayy 把当前行复制进 a 寄存器，再用 "ap 粘贴，就不会覆盖无名寄存器里的内容。:reg 可以查看所有寄存器的当前值。

系统剪贴板是 + 寄存器，"+yy 复制到剪贴板，"+p 从剪贴板粘贴。前提是 Vim 编译时带了 +clipboard，用 :echo has('clipboard') 检查，返回 0 就说明这个 Vim 不带剪贴板支持。服务器上的 vim 为了体积常常关掉这个特性，这时不必折腾，本地编辑完再传上去更省时间。

宏用来录制一段操作。普通模式下按 qa 开始录制到 a 寄存器，做完一套动作再按 q 停止，@a 回放，@@ 重复上一次回放。例如清理一份日志，每行开头是一段时间戳，要在行尾补一个分号：qa、0dw、$a;、Esc、j、q，然后 200@a。执行时留意失败的位置，宏一旦在空行上出错，后面的行会跟着乱。

替换与全局命令

替换的格式是 :[范围]s/旧/新/标志。% 代表整个文件，:%s/old/new/g 是全文替换；不带范围只作用于当前行；:10,20s/old/new/g 限定行区间。标志里的 g 表示一行内的所有匹配都替换，默认只换第一个；c 逐个确认，提示时按 y 替换、n 跳过、a 全部替换、q 退出。改生产配置时加 c 比一把梭稳妥。

Vim 的正则默认是 magic 模式，括号和加号要写转义。在模式开头加 \v 打开 very magic，之后 ()、+、? 都按常见写法来：:%s/\v(\w+) = (\d+)/\2 = \1/g 可以把 key = 1 交换成 1 = key。捕获组在替换串里用 \1 到 \9 引用，& 代表整个匹配。

:g/模式/命令 对匹配的行执行命令，:g/^#/d 删除所有注释行，:v/模式/d 删除不匹配的行。清理配置和日志时，这两条往往比写脚本快。

一份够用的 .vimrc

配置写在 ~/.vimrc。下面这份够日常使用：

number 显示行号。tabstop 决定 Tab 显示多宽，shiftwidth 决定 >> 和自动缩进移动几格，expandtab 把 Tab 写成空格；团队协作时这一条最能减少 diff 里的空白噪音。ignorecase 让搜索忽略大小写，smartcase 在输入里出现大写时自动切回大小写敏感。incsearch 边输入边预览第一个匹配，hlsearch 高亮全部结果。backspace 那行让退格键能跨过缩进和换行，不设的话在行首按退格没有反应。

映射统一用 nnoremap 这类 noremap 变体，避免递归展开带来的连锁反应。<leader> 是自定义前缀键，默认是反斜杠，改成逗号更顺手。改完执行 :source ~/.vimrc 立即生效，不用重启。

插件管理：只装需要的

2017 年常见的插件装法有这么几种。Pathogen 只做一件事：把插件放在 ~/.vim/bundle/ 下，靠调整 runtimepath 让 Vim 找到它们，安装就是 git clone，删除就是删目录。Vundle 在此之上做了声明式管理，在 .vimrc 里用 Plugin '名称' 列出，执行 :PluginInstall 安装。vim-plug 的用法接近，安装脚本更轻，用 :PlugInstall，当年已经有相当多人在用，但还不能说它是唯一选择。

插件按类别记即可：

  • 文件树：NERDTree，用 :NERDTreeToggle 开关侧栏。
  • 模糊查找：ctrlp，按文件名和缓冲区名查找，配合 ag 速度更好。
  • 语法检查：Syntastic 同步检查，保存时卡一下；ALE 走异步，大项目里体验更好。
  • 补全：YouCompleteMe 用 clang 做 C/C++ 补全，安装要编译，配置成本不低。

插件不求多。文件树和模糊查找解决“找文件”，语法检查解决“写完立刻知道错”，其余的等有明确痛点再装。装得太多，启动变慢、按键冲突，反而要花时间排查。

几个容易踩的坑

第一个坑是 Ctrl-S。在终端里按下它，屏幕立刻卡住，输入没有反应，很多人以为 ssh 断了。原因是终端软件的流控把输出暂停了，按 Ctrl-Q 恢复即可。Vim 里保存用 :w，不要把编辑器的习惯带进来。

第二个坑是粘贴时的自动缩进。从浏览器复制一段带缩进的代码，在插入模式里粘贴，会看到每行越来越往右缩。原因是 Vim 对新行做自动缩进，粘贴内容里的换行被当成了手动回车。办法是先 :set paste 再粘贴，粘完 :set paste! 关闭。Vim 8.0 能借助终端支持的 bracketed paste 识别粘贴，但服务器上的终端未必支持，:set paste 仍然最稳。

第三个坑是 root 下配置不生效。sudo vi 用的是 root 的环境，读的是 /root/.vimrc，不是你的 ~/.vimrc。要么把配置复制过去，要么用 sudoedit 以当前用户编辑，避免两头维护。

第四个坑是编码。文件里的中文变成乱码，先看 :set fileencoding 和 :set fileencodings。统一用 UTF-8：set fileencoding=utf-8，探测顺序写成 utf-8,gbk,latin1。Windows 上编辑过的文件可能带 BOM，用 :set bomb? 查看，必要时 :set nobomb 去掉。

速查表与小结

下面这张表按使用频率排列，不必背，先在服务器上照着敲，把最常用的十来条用熟。

Vim 的学习曲线陡，但前期只需要一小撮命令就能覆盖服务器上的大多数改动：进出模式、移动、删改、搜索、保存退出。把这几件事练成条件反射，再去补寄存器、宏和插件。练习顺序建议是先解决“进得去、出得来”，再练移动与删除，最后学搜索替换；每天在真实文件上改几处，比对着教程敲一遍有效。

配置不要一次抄一大份，遇到一个问题加一行，半年后自然长成适合自己的样子。真正要防的不是命令记不全，而是在错误的模式里使劲按键。
