Rust 智能指针 Box 与 Rc

所有权让 Rust 在没有垃圾回收的前提下管住了内存，但它只覆盖了“一个值一个所有者”这一种形态。真实程序里还会遇到递归类型、多个持有者、共享之后仍要修改、跨线程共享等情况，这时就需要标准库提供的几类智能指针。本文按 Box、Rc、RefCell、Arc 与 Mutex 的顺序讲清它们各自解决什么问题、代价是什么，再用一张对照表和一组常见坑帮助读者做选择。本文面向已经理解所有权与借用规则的读者，示例基于 Rust 1.60 与 2021 edition。

负载均衡策略与实现

把流量分给多台机器，看起来只是从列表里挑一台，做对却要同时兼顾算法、健康状态、会话与超时。本文从四层与七层的差别讲起，逐一拆解常见调度算法、一致性哈希、健康检查、重试与局部性，并给出一个 Go 语言的最小实现和 Nginx 配置片段。适合准备为系统补上流量分配这一环的读者。

服务注册与发现原理

微服务架构把单体拆成许多进程，调用关系从方法调用变成了网络请求。网络请求必须知道对方的地址，而地址在容器化和弹性伸缩的环境里几乎每天都在变。注册中心就是用来回答“现在有哪些实例、它们在哪里、还能不能用”的基础设施。本文从机制与语义出发，讲清楚注册、发现、一致性、健康检查这几件事，以及它们在真实故障中的表现。

CQRS 模式在后端中的应用

很多团队第一次认真讨论 CQRS，是在一张报表或列表页把数据库拖慢之后：写接口的耗时一直很稳定，查询却随着数据量增长越来越难优化，加索引、加缓存都只能续命几个月。本文从这种常见的失衡讲起，拆开命令与查询这两条路径，讨论读模型如何构建、投影如何更新、一致性如何向用户解释，以及 CQRS 与事件溯源到底是什么关系。读完之后，你应该能判断自己的系统该不该引入 CQRS，以及如果要引入，应该从哪一小块业务开始。

Rust 变量、常量与可变性

Rust 的变量声明看上去和别的语言差不多，写起来却很快撞上编译器的红线：改一个值要先加 mut，同名变量却能重复声明，常量与静态量又各有各的限制。本文从 let 绑定讲起，说明 mut 的真实含义、重新赋值与遮蔽的区别，再讨论 const、static 与 'static 生命周期，最后落到作用域、解构与类型推断这些日常写法。读完之后，应当能判断一段代码该用哪种声明，也能看懂 E0384、E0308 这类报错背后的规则。示例基于 Rust 1.63 与 2021 edition。

长任务拆分与断点续跑

批量导入、报表生成、数据迁移、模型预处理，这些任务的共同点是从几分钟跑到几小时，中途可能遇到进程重启、下游限流、单条脏数据。把它们塞进一个 HTTP 请求或一个后台线程，第一次失败就会暴露问题：进度归零、副作用重复、没人知道任务究竟停在哪里。本文从拆分、检查点、状态机、恢复、并发与可观测几个方面，给出一套不依赖特定工作流引擎的长任务执行模型，适合需要自己实现任务编排的后端工程师阅读。

分布式消息队列选型
