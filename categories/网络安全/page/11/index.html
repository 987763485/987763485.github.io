前端安全之 CSRF 攻击与防护

跨站请求伪造（CSRF）大概是前后端都容易低估的一类漏洞：页面没有 XSS，接口也做了登录校验，攻击者却能让受害者在不知情的情况下完成转账、改密码这类操作。本文从攻击成立的条件讲起，依次介绍同步令牌、双提交 Cookie、SameSite、Origin 校验等防护手段，并给出可以直接落地的自查方法。读者需要具备基本的 HTTP 与 Cookie 知识，读完后应能为自己的项目搭起一套完整的 CSRF 防线。

前端安全之 XSS 攻击与防护

把用户输入原样拼进页面，是前端最古老也最顽固的错误。XSS（Cross-Site Scripting，跨站脚本）并不依赖某个框架漏洞，它利用的是浏览器对 HTML 与 JavaScript 的解析规则：只要不可信数据落在了本该写代码的位置，浏览器就会把它当代码执行。本文从 XSS 的本质讲起，依次梳理三类攻击的数据流、几种常见上下文的编码方式，以及富文本、框架转义和 Cookie 属性的边界，最后给出一份可以照着做的排查清单。读者不需要安全背景，但需要写过表单回显和 DOM 操作。
