浏览器缓存机制全景

浏览器缓存是前端性能优化里性价比最高的一环：一次正确的配置，能让回访用户的静态资源请求几乎归零；一次错误的配置，能让用户拿着旧版本的 CSS 抱怨样式错乱，而你在本地怎么刷新都复现不了。它横跨 HTTP 协议、服务器配置与前端工程三个层面，任何一环理解不到位，都会以”改了文件不生效”的形式还回来。
