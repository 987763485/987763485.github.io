JavaScript 函数式编程入门：map/filter/reduce

map、filter、reduce 是 ES5 给数组加的三个方法，也是 JavaScript 函数式编程最常用的入口。它们看起来只是”语法糖”，但真正改变的是代码的书写方式：从描述”怎么一步步改”变成描述”要什么结果”。本文从对比与选型的角度，讲清三个方法的回调签名、与命令式循环的等价关系，以及实战中的常见误用。结论先给出：三者适用于”从数组到新数组或单值”的转换，不适合需要中断或产生副作用的场景。

jQuery 的 Deferred 与 Promise 模式

jQuery 1.5 在 2011 年初引入 $.Deferred 时，很多人以为它只是个”更好用的 AJAX 回调”。但这个对象真正改变的，是把异步流程从”往函数里传回调”翻转成”把返回值当成可等待的对象”。本文按 2014 年初的现状，把 $.Deferred、$.when、$.Callbacks 与 jQuery 1.7/1.8 的 then、pipe 一并讲清，重点剖析 jQuery 的 then 与后来 ES6 的 Promise 之间那些著名差异——尤其是 1.8 之前 then 的非标准行为这个坑。结论先放在前面：$.Deferred 是一套好用的工具，但它的 then 从来不是 Promise 的 then，混用两者心智模型必然出错。
