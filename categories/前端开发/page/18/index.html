CSS 中 z-index 与层叠上下文的秘密

z-index 在很多人心智里是一条数轴，数字大就盖住数字小。但浏览器实际管理的是一棵树：层叠上下文（stacking context）嵌套成层级，比较只发生在同一棵树杈内部。想通这一点，”子元素 z-index: 9999 干不过父级 z-index: 1“”transform 让 fixed 弹层错位”这些怪事就都是同一个答案。本文按笔者 2014 到 2015 年的踩坑实录展开，最后给一套能直接落地的 z-index 分层约定和调试手法。先说明一句：层叠上下文与 BFC 不是一回事，前者管绘制顺序，后者管布局，BFC 的触发条件与遮挡关系见《BFC块级格式化上下文原理与应用》，本文不再重叠。
