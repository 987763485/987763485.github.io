Embedding 模型评测

换一个 embedding 模型，线下评测涨了两个点，上线之后检索质量却没有变化，甚至更差——这是很多团队做语义检索时都会遇到的一次“打脸”。问题通常不在模型，而在评测本身：指标选错、评测集与业务分布不符、负样本太容易、切分时把答案泄漏进了查询，或者拿公开榜单的名次替代了自家场景的判断。本文讨论如何为 embedding 模型建立一套可信的评测方法，从指标定义、领域评测集构建、负样本设计，一直到维度与成本权衡、线上指标和迭代回归门槛。读者应已了解向量检索的基本概念，读完后能够独立设计并执行一次可复现的模型选型评测。

大模型流式输出实践

大模型一次生成几百个字，往往要花十几秒。这十几秒里，界面是空的，用户不知道程序是在算、在等网络，还是已经卡死。本文讨论如何用 HTTP 流式传输把这段等待拆开：从分块传输与 SSE 的协议细节，到增量解析、首 token 延迟、服务端解耦、背压、断线续传、代理缓冲，再到前端渲染与取消。读者读完应当能独立实现一条可观测、可中断、可续传的流式链路，并知道每个环节最容易踩的坑。

Transformer 架构完全解析

Transformer 是过去几年里被引用得最多、也被误解得最多的网络结构之一。本文不讨论具体产品、训练数据与线上部署，而是回到 2017 年的《Attention Is All You Need》，把注意力、多头、位置编码、残差与归一化、掩码、复杂度以及训练目标这些部件逐个拆开：它们各自解决什么问题，又为什么必须组合在一起。读完本文，读者应当能够对照一张结构图，说清一段文本从输入到输出究竟经过了哪些变换。本文假定读者写过简单的 PyTorch 模型，熟悉张量形状与矩阵乘法；大模型概念、向量表示与检索增强另有专文，这里只谈架构本身。
