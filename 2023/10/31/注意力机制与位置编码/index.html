注意力机制与位置编码

注意力机制常被简化成一句“让每个词看所有词”。本文拆两件事：注意力为什么值得用平方复杂度去换，被它丢掉的顺序又该怎样补回来——从正弦编码、可学习的绝对嵌入，到相对偏置、RoPE 与 ALiBi，最后落到长上下文与 KV 缓存。整体架构、残差归一化与训练目标另有专文；公式写成文字或伪代码，数字均为示意值。

注意力为什么值得用平方复杂度来换

循环网络把序列压成一条隐状态链 h_t = f(h_{t-1}, x_t)：时间维无法并行，第 t 步必须等第 t-1 步；相隔 n 个位置要 n 次递推才相遇，梯度沿同样长的路径衰减。卷积可以沿时间维并行，但单个核只见窗口，远距离交互仍要靠堆层换路径长度。

自注意力换了交易方式：用平方级计算量买“任意两个位置一步直达”，路径长度与距离无关，整条序列一次矩阵乘法算完。这笔交换划不划算，取决于任务里长距离关系有多重要；代价则是算力与显存随长度平方增长，以及对顺序天然无感。

三个角色与缩放点积

设输入 X 的形状为 (n, d)，n 是长度、d 是维度，三个不同的线性变换给出 Q、K、V：每个位置分饰三角，发出查询、提供可被匹配的键、给出待汇总的内容，所谓“自”注意力就是指三者来自同一序列。取第 i 位的查询与全部 n 个键逐个点积，过 softmax 归一化成权重，再对值加权求和作为输出；权重连续且可导，关注谁由模型自己学出来。

分数还要除以根号 d。若各分量独立、零均值、单位方差，d 维点积的标准差约为根号 d：尺度偏大时 softmax 迅速贴近 one-hot、梯度消失，尺度偏小时权重趋近均匀、退化成求均值。除以根号 d 把分数拉回常数级，这就是缩放点积注意力。

多头买到了什么

一次注意力只做一次加权平均，一轮只能表达一种关系。多头把 d 维空间切成 h 份，每份维度 d_h = d / h，各头在自己的子空间里独立算一次注意力，拼接后再投影回 d 维，总计算量近似不变。不同头会分化出各自的模式，但实践中不少头冗余，而头切得越多单头维度越小、语义容量越窄，h 与 d_h 需要权衡。

因果掩码：训练并行不等于生成并行

语言模型要求第 i 个位置的输出只依赖前 i 个词。实现上不必删掉未来 token 再循环 n 遍，只需在 softmax 之前把分数矩阵中“被查询位置晚于查询位置”的条目置为负无穷，归一化后权重恰好为零；下三角矩阵一次算完，就同时得到 n 个位置各自“只看前文”的表示，损失沿位置相加。

界限要划清：并行只发生在训练阶段的一次前向之内，自回归生成仍是一个 token 接一个；何况掩码告诉每个位置的不过是“我前面有几个词”，它保证可见性而不是顺序。

平方项究竟落在哪里

按长度 n 拆开一层的成本：线性投影、逐位置前馈、残差与归一化随 n 线性增长，注意力分数矩阵与两次加权求和随 n 平方增长，因为每个位置要和每个位置比一次。当 n 与 d 同量级或更大，平方项开始主导开销。平方不是实现低效的副产品，而是“任意位置两两交互”这个语义的定价，融合做得再好也不改变数量级。后果是长提示的 prefill 算力随长度平方抬升，首 token 延迟变大，上下文长度由此成为真实的资源维度，而不是可随意填写的额度。

位置编码为什么不能省

置换等变性

不含位置信息的注意力是置换等变的：把 X 的行按某个排列重排，Q、K、V 同步重排，分数矩阵被同一个置换作用，softmax 沿行归一化后加权求和，输出也就只是原输出被重排一遍，逐位置前馈同样保持这个性质。于是把词序彻底打乱，模型看到的仍是换了行的同一份计算，它无法区分“猫追狗”和“狗追猫”。顺序必须显式注入，方式无非两种：给每个位置一个向量参与计算，或者不给向量、只在分数上动手脚，这两条路对长度的敏感度截然不同。

绝对位置编码：正弦与查表

正弦编码给位置 pos 构造一个 d 维向量，偶数维取 sin(pos / 10000 ** (2i / d))，奇数维取对应的余弦，每一维都是周期不同的正弦波，波长从 2π 按几何级数拉到一万倍的 2π。它有两个关键性质：平移固定 k 相当于每维做同一个旋转，pos 加 k 处的信号可由 pos 处的正弦与余弦线性表出，相对位移天然可表达；分频提供多尺度，高频区分相邻位置、低频给出粗粒度坐标。它不带参数，也不设长度上限。

可学习的绝对位置嵌入是另一条路：建一张 (max_len, d) 的表，把第 pos 行加到词嵌入上。实现只多一层查表，位置语义全交给模型自己学，是原论文与随后几代模型的默认选项；缺点也来自“表”这个形态——上限被表大小写死，越界只能截断或回绕，且越靠前的位置被踩得越频繁，表尾几乎没有更新量。

越过训练长度就失效

两条路都会遇到外推问题：在长度 N 内训练，推理一旦超过 N，困惑度上升、需要看全文的检索式任务命中率下降。原因有三层且互相叠加：表式编码在 N 之后没有定义；正弦编码虽无上限，模型也只见过 0 到 N 之间的相位组合，更大位置的分数落在训练分布之外；训练样本本身从不包含超过 N 的依赖。顺序一旦被表达成绝对坐标，就与训练长度绑定，长度一变，坐标的意义就变，此后的演进主线因此是把表示改成只依赖相对位移。

相对位置偏置：只往分数里加一项

最早的一类修法是丢掉绝对向量，给分数补一项：缩放点积加上只依赖距离 i 减 j 的可学习标量。距离本身也会越过训练范围，做法是分段取桶，把更远的距离裁剪到最后一个桶，同桶共享一个偏置，让“很远”退化成一个可复用的档位。这条路线不改动嵌入，只在打分时插一笔，天然偏向近邻；每个头有自己一整套偏置，同层里于是有的学成局部、有的学成远程。T5 式的分桶偏置是它的代表，也比把位置差编成向量的显式相对表示更省算力。

RoPE：把位置写成旋转

RoPE 的构造可以从正弦编码的性质反推：既然平移固定 k 相当于每个二维分量做一次旋转，那就把旋转直接作用到查询与键身上。把 d 维向量按维度两两分组，第 i 组分配一个角频率，取法与正弦编码同源、从接近一到很小按几何级数排开；位置 m 处的查询，第 i 组分量旋转 m 乘 θ_i，键按自己的位置做同样的事。

关键性质在内积上：位置 m 的查询与位置 n 的键点积时，两次旋转合并成一次角度为 m 减 n 的旋转，分数因此只依赖相对位移与两个向量本身，绝对坐标在打分环节被消掉。位置信息既不查表也不加偏置，而是内嵌在 Q、K 投影之后随每次前向现算；不同维度组承担不同频率，高频管相邻、低频管长程，等于自带一份多尺度相对位置谱。它对长度也更友好：超出训练长度时不再需要一张并不存在的表，只是相位差落到分布之外，效果仍会退化，但退化方式与绝对编码不同，可以靠调整角频率缓解——这正是位置插值的落点。

ALiBi：给距离直接打分

ALiBi 比相对偏置更极端：不要位置嵌入，也不学习偏置，直接在分数上减去距离的线性惩罚——第 h 个头取固定斜率 λ_h，乘上 i 与 j 之间距离的绝对值。斜率按头排成几何级数，一半细密一半稀疏，同层里于是同时存在只看近处的头和能看远处的头。它把“偏向局部”写成先验：距离越远扣分越多，长程注意力要胜出就得提供足够强的内容相关性。

先验换来了外推：训练只用一千级别的长度，推理时斜率不变、惩罚依旧单调，可以直接跑到远超训练长度，不必重训、不添参数。代价也明确：惩罚是无条件的，若任务要求远处内容与近处内容被一视同仁，例如在超长上下文里定位一条不起眼的信息，单调衰减会持续压制它。取舍之下 RoPE 的“软”更受欢迎：它不预设距离必须衰减，长程关系留给数据决定，因而在 2022 到 2023 年的开源模型里成为主流选择。

长上下文的几条路

位置编码的账最终要在长上下文上结，三条路子各省一笔。

位置缩放与插值

最省事的扩长办法是别越过训练时的位置范围：把新长度 M 上的位置线性压缩回 0 到 N 区间，乘一个缩放因子再喂进原来的编码，正弦或 RoPE 的相位都不再越界。这就是位置插值，好处是复用已有权重、不必从头预训练。代价是高频维度上相邻位置被挤得更近，局部分辨率下降，实践中会按频段做非均匀缩放，再拿少量长文本微调找回精度。

稀疏、局部与滑窗

第二条路直接砍平方项：每个位置只与窗口内的邻居算注意力，复杂度从 n 的平方降到 n 乘窗口宽度；再留少量全局位置做远距离的汇聚点，或按层交替使用滑窗与全局，靠堆叠接起两跳。麻烦有两个：远距离交互重新依赖层数，路径长度又回来了；更棘手的是工程侧，稀疏模式打乱了规整的矩阵乘法，没有专门算子就吃不满硬件，理论复杂度省了、实际延迟反而涨。

外部记忆交给检索

第三条路不打算让注意力看全所有内容，而是把长文本放在窗口之外，先检索、只把命中的片段拼进上下文，注意力只为窗口长度负责。代价是把长距离依赖换成了检索质量：召回不到的片段等于不存在，跨片段的顺序与指代还得靠拼窗顺序重新安排。检索增强另有专文，这里只强调它与位置编码是两笔独立的账。

KV 缓存与显存账

位置编码决定模型能不能读长，KV 缓存决定读长时贵不贵。解码第 t 步只需要一个新的查询向量，此前所有 token 的键与值却都要参与打分；若每步重算，代价随步数平方增长，于是把它们存下来：每层每头各留一份 K 与 V，长度随已生成 token 数线性增长。

它贵在哪可按量级估：缓存字节数是二（K 与 V）、层数、长度、键值总维度与字节数的乘积。取层数 32、总维度 4096、长度 4096、半精度两字节，单条序列的缓存约两 GiB；长度拉到三万二，同一算式把它推到十六 GiB，比权重本身还大。两个阶段的瓶颈也因此不同：prefill 是算力受限，decode 是显存与带宽受限，每生成一个 token 都要读一遍整份缓存。缓解手段不改注意力语义：缓存分块存放以避开内存碎片、量化键值、或者让多个查询头共享一份 K 与 V。

小结

这条线可以这样收：自注意力用平方复杂度换来一步直达与全序列并行，缩放让 softmax 留在梯度充足的区间，多头在子空间里多买几种关系，掩码买到训练并行而非生成并行。顺序是这笔交换的隐性代价，绝对坐标类编码把它记在训练长度上，于是演进转向相对位移——分桶偏置、RoPE 的旋转、ALiBi 的惩罚。长上下文的三条路，是在相位越界、平方项、外部存储三处各省一笔；读长文先看位置方案与外推是否配套，跑服务先算缓存显存。
