Transformer 架构完全解析

Transformer 是过去几年里被引用得最多、也被误解得最多的网络结构之一。本文不讨论具体产品、训练数据与线上部署，而是回到 2017 年的《Attention Is All You Need》，把注意力、多头、位置编码、残差与归一化、掩码、复杂度以及训练目标这些部件逐个拆开：它们各自解决什么问题，又为什么必须组合在一起。读完本文，读者应当能够对照一张结构图，说清一段文本从输入到输出究竟经过了哪些变换。本文假定读者写过简单的 PyTorch 模型，熟悉张量形状与矩阵乘法；大模型概念、向量表示与检索增强另有专文，这里只谈架构本身。

从串行瓶颈说起

在 Transformer 之前，处理序列的主力是循环神经网络。它的核心是一个递推式：h_t = f(h_{t-1}, x_t)，第 t 个时间步的隐状态由上一时刻的隐状态和当前输入共同决定。这个设计很自然，却带来两个难以回避的代价。

第一，它无法在时间维度上并行。要算 h_t，必须先算完 h_{t-1}，整条链只能一步步走。GPU 擅长成千上万个乘加同时进行，循环网络却把这种能力浪费了大半。

第二，长距离依赖的传播路径太长。相隔 n 个位置的两个词，信息要经过 n 次递推才能相遇，梯度也要沿同样长的路径反传，容易衰减或爆炸，模型对“开头那个词”的记忆变得不可靠。门控与梯度裁剪缓解了症状，却没有改变路径随距离线性增长的事实。

卷积是另一条路：时间维上可以并行，但单个卷积核只看得到局部窗口，要让远处位置交互只能堆叠多层，路径同样随距离增长。注意力换了思路：让任意两个位置直接建立联系，路径长度变成常数，所有位置也能同时计算。代价是它对顺序毫无感知，把一句话打乱，结果只是换了行序，这要靠位置编码来补。

注意力并非 Transformer 首创，它早就在机器翻译里用于对齐词与词。Transformer 的主张是：去掉循环与卷积，只留注意力，再配上前馈网络、残差与归一化，堆成可重复的块。2017 年的论文证明这条路可行，训练成本还更低。

注意力的三个角色：Query、Key 与 Value

理解注意力最省力的方式，是把它想成一次软性查表：数据库里每条记录存着键和值，来了一个查询，就拿它与每条键比相似度，再按相似度对所有值加权求和。权重是连续的，不是非此即彼的硬选择，因此整个操作可导，可以端到端训练。

查询、键、值并非外部给定，而是同一段输入经过三个不同线性变换得到。设输入矩阵 X 的形状为 (n, d_model)，n 是序列长度，三个变换分别给出 Q = XW_Q、K = XW_K、V = XW_V。于是每个位置都同时扮演三个角色：它发出一个查询，提供一个被查询的键，也提供一份待汇总的内容。所谓“自”，指的就是查询与键值来自同一个序列。

计算过程可以写成一行：Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V。QK^T 得到一个 (n, n) 的分数矩阵，第 i 行第 j 列表示位置 i 的查询与位置 j 的键有多匹配；除以 sqrt(d_k) 做缩放；softmax 按行归一化，使每一行的权重之和为 1；最后用权重矩阵去乘 V，得到 (n, d_v) 的输出。输出第 i 行就是所有位置的值按第 i 行权重混合的结果。

缩放这一步值得多说一句。若 Q 与 K 各维近似独立、均值为 0、方差为 1，点积就是 d_k 个随机项之和，方差约为 d_k。维度越大，分数越分散，softmax 越容易饱和成接近 one-hot 的分布，梯度趋近于 0，训练随之变慢。除以 sqrt(d_k) 把方差拉回 1 附近，让 softmax 工作在梯度较舒服的区间；改动很小，却是论文做过消融、确认有效的细节。

多头注意力：并行的多个观察视角

一次 softmax 只能给出一组权重，也就只能表达一种“关注方式”。但语言里的关系多种多样：有的要看相邻词，有的要找先行词，有的要对齐从句边界；让一组权重承担所有职责，结果往往是折中。多头注意力的做法很直接：把查询、键、值投影到 h 组低维子空间，各自独立做注意力，再把结果拼起来。

原论文取 d_model = 512、h = 8，于是每个头的维度是 d_k = d_v = 512 / 8 = 64。这里有一个容易被忽略的设计：头的维度是被除小的，而不是每个头都保持 512 维。这样 8 个头加在一起的总参数量与计算量，和一次 512 维的单头注意力大致相当，多头并不是靠堆算力换取表达力，而是把同样的预算拆成多份，让模型在多个子空间里各看一面。

拼接之后还有一步线性变换。把 h 个 (n, 64) 的输出沿特征维拼成 (n, 512)，再乘一个形状为 (512, 512) 的输出矩阵 W_O。若没有这一步，各头的信息只是并排放着，后续层无法对它们做交叉组合；W_O 让模型自己学习如何把不同视角的结论混合成一个表示。形象地说，每个头交一份报告，W_O 负责汇总。

不过，头与头并不总是泾渭分明。有些头确有可解释的模式，有些则高度冗余，剪掉后性能几乎不变。“每个头负责一种语法现象”是过于整齐的想象；多头更实际的价值，是提供多条独立的投影与组合路径。

位置编码：把顺序还回来

自注意力是置换等变的：把输入位置打乱，输出只是跟着打乱，模型分不清“猫追狗”和“狗追猫”。语言的意义高度依赖顺序，必须在输入里显式注入位置信息。

原论文选择的是正弦位置编码。对位置 pos 和维度下标 i，偶数维取 sin(pos / 10000^(2i/d_model))，奇数维取对应的余弦。这样每一维都是一条不同频率的正弦波：低维变化快，高维变化慢，波长从 2π 一直延伸到 10000 · 2π。可以把它类比成二进制计数，低位频繁翻转，高位缓慢进位，若干条波叠在一起，就为每个位置刻出一枚近似唯一的指纹。

选择正弦还有一个数学上的好处：对任意固定的偏移 k，PE(pos + k) 可以写成 PE(pos) 的线性变换。这意味着相对距离在编码里有现成的线性表达，模型可以较容易地学到“往前看三个词”这类模式。位置编码与词嵌入相加而非拼接，相加前词嵌入通常乘以 sqrt(d_model)，让两者量级接近。

另一种做法是可学习的位置嵌入：准备一张 (max_len, d_model) 的表，把位置当作词表里的符号去查。它实现简单，在数据充足、长度固定的任务上与正弦编码效果相当。缺点同样明显：表的行数就是长度上限，超出训练时见过的范围就没有对应向量。正弦编码在形式上没有这个上限，但实际外推效果也远非理想，位置分布一旦偏移，注意力仍会失准。正因如此，后来才有相对位置、旋转位置编码等一系列改进，本文不展开。

一层里有什么：残差、归一化与前馈网络

把注意力放进一个可堆叠的块里，还需要三样东西：残差连接、层归一化和前馈网络。原论文的每个子层都写成 LayerNorm(x + Sublayer(x))，先做残差相加，再归一化。

残差连接解决深层网络的训练问题。注意力与前馈网络都是复杂的非线性变换，若每层都彻底改写输入，梯度反传几十层后很容易衰减。加上恒等通路，梯度可沿捷径直接回流，每层只需学习“在原有表示上改动什么”。这也要求子层输入输出维度一致，所以 d_model 始终保持 512，中间膨胀只发生在前馈网络内部。

层归一化沿特征维计算均值与方差，对每个位置的 512 维向量单独归一化。它不依赖批大小，也不受序列长短影响，适合变长、小批量的场景。原论文把归一化放在残差相加之后；后来的实现更常放到子层之前，训练更稳定，但那是工程调整，不影响对结构的理解。

前馈网络是两层的逐位置全连接网络：先升到 d_ff = 2048，过 ReLU，再降回 512。它对每个位置独立作用，位置之间不交换信息，可以看成两个核大小为 1 的卷积。这部分常被低估，其实它占了每层参数的大头：注意力按相关性搬运信息，前馈网络对每个位置做非线性加工，两者缺一不可。

编码器与解码器的差别，集中在“能看到什么”。编码器每层只有自注意力与前馈网络，所有位置彼此可见，每个词的表示都融合了整句上下文，适合理解类任务。解码器每层多一个掩码自注意力，再多一个交叉注意力：查询来自解码器当前状态，键和值来自编码器输出，让解码器生成每个词时回看源句。交叉注意力是翻译这类序列到序列任务的桥梁。

掩码的作用需要单独说明。训练解码器时手里有完整参考答案，可以一次性喂进去并行计算；但预测第 t 个词时，模型只许看前 t-1 个词，否则瞟一眼下一位置就能抄答案，损失会漂亮得毫无意义。做法是把分数矩阵中“当前位置之后”的元素置为负无穷，softmax 后权重恰好为 0。推理时模型本来也只见过已生成的词，掩码只是把同一约束提前写进了并行计算。

复杂度：平方项从哪里来

注意力把任意两点的路径缩到常数，但不是免费的。每层自注意力的时间与显存都随序列长度 n 平方增长：分数矩阵是 n × n，h 个头就是 h 份。每层计算量约为 O(n^2 d)，前馈网络则是 O(n d^2)；n 小的时候前馈占主导，序列一长，二次项迅速压倒一切。

显存往往比时间更早成为瓶颈，因为中间矩阵要留着供反传。推理时虽不必保存梯度，但每生成一个词都要对全部历史算注意力，键值缓存随长度线性增长，注意力本身仍是平方级。长上下文的困难正来自这里：成本增长过快，位置编码外推不理想，注意力还会被大量无关位置稀释。常见缓解手段有局部窗口、稀疏注意力、低秩近似、梯度检查点，以及减少显存读写的分块实现，它们各自缓解一面，并未改变二次复杂度的基本盘。

训练目标与自回归生成

训练目标很朴素：给定前 t-1 个词，预测第 t 个词，整句概率连乘取对数，等价于逐位置交叉熵。输入与目标错开一位，一次前向就得到所有位置的损失，取平均后反传。这里用的是 teacher forcing：每步喂给模型的是真实前缀，而不是它自己上一步的输出。好处是所有位置可以并行、训练稳定；代价是训练与推理不一致，推理时模型只能吃自己生成的词，一步错可能步步错。

推理因此是自回归的：每步取最后位置的输出，经 softmax 得到词表分布，按贪心或采样选一个词，追加到末尾，再走下一步。键值缓存让历史表示不必重算，但整体仍是逐词推进。需要区分的是，编码器-解码器结构适合翻译这类有源句的任务；只保留解码器、用因果掩码做语言模型的路线，则是后来大模型的主流形态。大模型概念、向量表示与检索增强另有专文，本文只关心这台机器本身。

小结

Transformer 的每个部件都在回答一个具体问题：注意力解决路径长度与并行，多头提供多个视角，位置编码补回顺序，残差与归一化让深层可训，掩码保证训练时看不到答案。代价是随序列长度平方增长的计算与显存，这也是长上下文始终是工程难点的原因。理解了这套结构，再去看各种变体与优化，就不容易被名词牵着走。
