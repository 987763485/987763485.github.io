new 操作符到底做了什么

new Foo() 是 JavaScript 里最常用的语法之一，但很多人说不清它背后到底发生了什么。面试里问”new 做了哪几件事”，能答全的不少；再往下问一句”如果构造函数返回一个对象会怎样”，就开始含糊了。这篇从规范层面把这四步拆开讲，然后自己动手实现一个 new，最后聊聊不规范使用会惹出什么麻烦。

要理解 new，先记住一个前提：JavaScript 里没有”类”这个概念（ES6 的 class 要到 2015 年才有），构造函数只是被 new 调用的普通函数。所以 new 做的事，其实是”给一次普通的函数调用套上一层造对象的壳”。

new 的四步

new Foo(arg1, arg2) 等价于下面四步：

  1. 创建一个新的空对象。
  2. 把这个对象的 [[Prototype]]（也就是内部原型链接）指向 Foo.prototype。
  3. 以这个新对象为 this，调用 Foo，把参数传进去。
  4. 如果 Foo 返回了一个对象，就用这个返回值；否则返回第一步创建的那个对象。

第 4 步是最容易被忽略的。构造函数本质上是个函数，函数就可以 return。规范规定：只有当返回值是对象（引用类型）时才采用它，返回原始值则被无视。

flowchart TD
  A[执行 new Foo] --> B[创建空对象 obj]
  B --> C[把 obj 的原型指向 Foo.prototype]
  C --> D[以 obj 为 this 执行 Foo]
  D --> E{Foo 的返回值是对象吗}
  E -->|是 对象或函数| F[返回该返回值]
  E -->|否 原始值或没有 return| G[返回 obj]

第三条演示了这条规则的实用价值：工厂模式下构造函数可以返回一个已有的单例或另一个构造函数的实例，调用方无需关心内部是新建还是复用。

prototype 的赋值时机

一个常见困惑是：Foo.prototype = {...} 之后，之前用 new Foo() 造出来的对象会不会变？答案是不会，但新造的对象会变。

原因是第二步做的是”把新对象的原型链接指向 Foo.prototype 这个对象”。链接一旦建立就固定了，之后你给 Foo.prototype 重新赋值，只是让 Foo.prototype 这个属性指向另一个对象，老实例的内部链接还指着原来那个。

所以”给原型加方法用 Foo.prototype.x = ...，要整体替换原型就直接赋值”，两种写法效果不同，混用时容易出诡异 bug。另外，整体替换原型会让 constructor 属性丢失（新对象上没有 constructor），需要的话得手动补 Foo.prototype.constructor = Foo。

ES5 的严格模式能挡住这个坑：严格模式下函数内的 this 不再默认指向全局对象，而是 undefined，给 undefined 赋值会直接抛错，让你立刻发现漏写 new。

养成习惯：在构造函数第一行加 'use strict'，或者用大写作标识并在文档里约定必须 new。

方法挂原型上，还是挂 this 上

顺着 new 的第二步，可以解释一个更实用的选择：构造函数里的方法到底该写在 this 上，还是写在 prototype 上。

两种写法调用方式完全一样，区别只在内存与查找路径。写 this.say 时，每 new 一次就创建一个新的函数对象，一千个实例就是一千个功能相同、互不相干的函数；写 prototype.say 时函数只有一份，实例通过原型链找到它。实例多的时候差距明显，所以默认做法是把方法放原型上，this 上只放每个实例不同的数据。

查找时的优先级也值得一提：实例自身的属性会”遮蔽”原型上的同名属性。

这行 delete 的结果常被用来验证”原型链查找”是否真的理解：删除自身属性后值并没有消失，而是回落到原型。new 的第二步建立的链接，正是这条查找路径的起点。

不能提的 new.target

ES6 给 new 加了一个元属性 new.target，用于判断函数是否被 new 调用。本文写作时它还没有进入任何主流浏览器，因此不展开。2013 年的替代方案就是上面两种：严格模式报错，或在函数体内显式判断 this instanceof 构造函数。

小结

new 的四步是：建对象、链原型、以之为 this 执行构造函数、按”返回对象则用之”的规则决定返回值。手写 objectFactory 是把这四步落到代码里的最佳练习，也是检验是否真懂的标准。要注意 Foo.prototype 重新赋值会让老实例失链、instanceof 只认原型链不认出处、以及忘写 new 在非严格模式下会静默污染 window。把这几处连起来看，就能明白 JavaScript 的”面向对象”完全是原型链加一次普通函数调用的组合，new 只是给这组合起了一个顺手的名字。
