CSS 实现箭头、三角与对话框气泡

本文属于《HTML 与 CSS》第 37/62 篇
上一篇系列目录下一篇

工具提示、下拉菜单、聊天气泡，这些组件都少不了一个小箭头或者小三角。刚入行那会儿我的做法是切一张背景图，后来发现页面一改配色就要重新出图，维护成本极高。本文把这几年攒下的几种纯 CSS 实现整理一遍，从最基础的 border 三角到带尾巴的气泡，全部不依赖图片，只靠 border、定位、transform 和伪元素。

原理：一个元素怎么变成三角形

浏览器里没有「三角形」这个图形单位，所有的 CSS 三角都是拼出来的。最经典也最容易讲清楚的是 border 三角法。

先回顾 border 的拐角模型。当一个元素宽高为 0，四条边框都很粗时，每条边框其实都是一个梯形，相邻边框在拐角处斜切。把另外三条边框设为透明，只留一条有颜色，看到的就是一个梯形；继续把边框宽度调成上边框 0、左右边框做成等宽，就得到了一个实心三角。

四个方向只要换哪一条边框着色即可：border-top-color 得到尖角向下的三角，border-bottom-color 得到尖角向上的三角，border-left-color 与 border-right-color 分别得到朝右和朝左的三角。

这里的关键点是：宽高必须为 0，否则看到的不是三角而是带缺口的方块；四条 border 的宽度可以不同，做出不等边三角，但同一条边的左右两段宽度必须相等，否则三角会歪。

一个不为人知的小细节：这个三角实际上可以当作一个盒子来定位。因为它有确定的盒模型尺寸（四条边框宽度之和），可以用 margin 和 position 精确摆放，这就为后面做气泡尾巴打下了基础。

五种做法的横向对比

按当时项目的使用频率，我把它们分成五类，各自有明确的适用场景。

做法 实现要点 能否带边框 能否渐变填充 兼容性 适用场景
border 透明三角 宽高 0，三条边框透明 否 否 全兼容 实心小箭头，提示框尖角
两个三角叠放 外层深色、内层浅色错位叠 是 否 全兼容 带描边的气泡尖角

下面逐个展开。

border 透明三角

最基础也最常用，上面已经讲过。它的短板很明显：不能加边框，也不能用渐变色填充，因为 border 无法设置渐变（2013 年尚无 border 渐变的标准实现）。所以实心三角场景用它，需要描边的场景就得换方案。

两个三角叠放

要做出带边框的气泡尖角，思路是用两个三角错位叠放：下面垫一个颜色深一点的、尺寸大一点的三角充当边框，上面盖一个和气泡底色一致的、尺寸小一点的三角。两层之间只差 1px 到 2px，视觉上就是一条 1px 的描边。

注意内层的 left 要比外层多 1px，top 要比外层小 1px 的负值偏移。这个 1px 的错位就是描边宽度，改大就会得到更粗的边框效果。

旋转方块法

如果气泡用了渐变背景，两个三角叠放就不够用了，因为内层三角只能填纯色，盖不住渐变的边缘。这时候用旋转方块：做一个正方形，transform: rotate(45deg)，同样内外两层错位，内层用与气泡相同的渐变，就能得到带描边的渐变尖角。

内层方块的 background-position 需要试，目的是让渐变看起来是从气泡内部连续延伸出来的，而不是重新开始一段渐变。这是旋转方块法最麻烦的地方，也是它不如叠放三角常用的原因。

字符法

最简单粗暴：直接往页面里放一个字符。◆ 是实心菱形，▼ ▲ 是实心三角，◢ 一类还可以做阴影效果。

优点是写起来最快，缺点是可控性差：不同字体下字符的尖角角度、大小、基线位置都不一样，无法精确控制尺寸，也没法加边框。只适合快速原型，或者对精度要求不高的下拉指示箭头。

transform 旋转法

CSS3 的 transform 在 2012 年后现代语法稳定下来（transform: rotate(45deg) 这种写法），2013 年主流浏览器已经支持，IE9 也支持。做法是把一个细长的矩形旋转 45 度当作尖角，天然带边框、可以渐变。

这里只给方块的 border-top 和 border-left 上色，旋转 45 度之后这两条边正好构成朝上的两条描边，另外两条边被气泡本体遮住。如果尖角朝下、朝左、朝右，就换成另外两条边的组合。这个方案写起来比两个三角叠放更简洁，也是 2013 年之后最推荐的做法。

用 transform 做一个完整的对话框气泡

把前面的碎片拼起来，就是一个完整的气泡组件。核心是三块：气泡本体、尾巴、可选的关闭按钮。尾巴用旋转方块，圆角和阴影用 CSS3，阴影用 box-shadow 加一点层次。

::before 在这里起的是「补阴影」的作用：旋转方块的右下两条边会带上一小段本体的 box-shadow，看起来像毛边，用一个白色矩形把它压掉即可。这是实际项目里几乎必然要处理的一个细节。

常见坑

坑一：IE8 及以下不支持 ::before 与 ::after。2013 年如果还要照顾 IE7，只能用真实 DOM 元素加一个 span 当三角，或者干脆用背景图。判断标准很简单：只要项目不需要支持 IE8 以下，伪元素方案就是首选。

坑二：父元素不能 overflow: hidden。三角是靠 position: absolute 探出父元素边界的，一旦父级裁切，三角直接被切掉。带滚动条的气泡要特别注意，把尾巴做在滚动容器外面。

坑三：z-index 层级。旋转方块如果盖在本体上面，会把气泡的上边框盖住，需要给尾巴设置合理的 z-index，或者把它放在本体之后绘制。伪元素的默认层级在文本之上，多数情况没问题，但遇到有背景图的复杂组件就要留神。

坑四：对齐基线。字符法的字符自带行高和基线偏移，在按钮里垂直居中时经常差几个像素，用 line-height 与 vertical-align 反复调，不如直接换 border 三角。

坑五：尾巴的位置与气泡宽度绑定。如果气泡宽度是百分比，用 left: 40px 固定尾巴位置在窄屏下会跑到气泡外面。稳妥做法是用 left: 10% 这类相对值，或者给气泡设 min-width。

小结

CSS 做箭头和气泡的五种做法可以这样选：实心小三角用 border 透明法，带描边的气泡用两个三角叠放或 transform 旋转方块，需要渐变填充时只能选旋转方块，快速原型用字符法。2013 年的现实是 ::before 与 ::after、transform、border-radius、box-shadow 都已可用，只有 IE8 及以下需要单独降级。真正容易出错的从来不是三角本身，而是它与阴影、层级、溢出裁切、百分比宽度之间的相互影响，这些细节需要在具体组件里反复调。掌握原理比记住代码重要：border 的梯形拼接是根，旋转方块是表，其他做法都是从这两条路演化的。
