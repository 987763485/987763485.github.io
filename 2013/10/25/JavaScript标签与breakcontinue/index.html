JavaScript 标签与 break、continue

break 和 continue 大概是 JavaScript 里最早被学会、也最少被认真看完的两个关键字。多数人停在”break 跳出循环、continue 跳过本次”的层面，然后一辈子再没往下看——直到在嵌套循环里写出一个需要跳出两层循环的需求，才发现语言其实早就给了答案：标签。这篇把标签语法、break label 与 continue label 的语义、几种循环里的行为差异、以及那些常见的误用一次讲清。内容不复杂，但每一条都能在代码审查里遇到。

标签是什么，以及它不是什么

标签就是一个标识符加一个冒号，放在语句之前，给这条语句起个名字：

标签本身不改变任何执行逻辑，outer: 加上或不加上，这段代码跑起来完全一样。它的唯一作用是给 break 和 continue 提供一个可指定的目标。这一点和 Java 的 goto 有本质区别：JavaScript 没有 goto，你不能”跳到”某个标签处执行，只能在 break 和 continue 里引用标签，而且引用的位置还有严格限制——标签必须写在它作用的语句外面（内层），不能从外层跳进内层。也就是说，break outer 只能写在这个循环内部，写在循环外面引用一个循环标签是语法错误。

标签的命名遵循标识符规则，通常用描述用途的词，比如 outer、rowLoop、search。保留字不能当标签名。

标签在 switch 与块级语句里

标签和 switch 的关系最容易被误解，因为 break 在 switch 里的语义与在循环里并不同。

在 switch 里，break 的作用是结束这个 switch 语句，控制流跳到它后面，与循环毫无关系。这不是特殊设计——switch 本身就是一条语句，break 作用于”最内层的可 break 语句”，只是恰好这里是 switch 而不是循环。

由此可以推出两个推论。第一，switch 写在循环里时，break 只结束 switch，不会结束循环——这是经典的”为什么 break 没退出循环”问题的答案。

第二，想从循环里的 switch 里直接结束整个循环，可以给循环加标签，用 break label。但更常见的做法是把 switch 抽成函数然后 return，或者用标志变量——哪种可读性更好取决于上下文。

break 与 continue 在四种循环里的行为

把 break 和 continue 放进 for、for...in、while、do...while 里逐一看一遍，break 的行为是一致的，continue 的差异只在”下一次迭代”由谁推进。

do...while 跳到条件判断，注意它至少执行一次

这张表里藏着一个真实的 bug 来源：while 循环里 continue 用不好会造成死循环，因为更新语句在循环体末尾，continue 会跳过它。

do...while 的”至少执行一次”语义则意味着循环体顶部的 break 和 continue 也不能违背这一点：continue 在 do...while 里是先跳到条件判断，而不是跳到循环体开头，这个细节和 while 不同。

常见误用与替代方案

标签的争议一直存在，批评者的理由很直接：它让代码的控制流变得不直观。阅读代码时，break 跳出的是哪一层，需要回头找标签定义在哪，心智负担比顺序执行的代码高。多层嵌套本身已经是需要重构的信号，标签只是让这个信号变得”能过且不报错”。

几条实践建议：

  • 能抽函数就抽函数。 上面二维查找的例子，如果逻辑允许包在函数里，return 比任何标签都清晰。重构不动的时候才考虑标签。
  • 标志变量只在该死的时候用。 单层循环里 break 就够，两层以上、且不能抽函数时，标签优于标志变量。别为了一层循环引入标签，那是纯噪音。
  • 警惕 continue 的位置。 while 和 do...while 里的 continue 要确认更新语句在它之前；for 里没有这个问题，因为更新表达式归引擎管。
  • 标签不是 goto。 不能跳到标签处，只能从标签内部跳出或继续。想清楚这条边界，很多”用标签实现奇怪控制流”的念头会自己消失。

小结

标签是 label: statement 形式的语法，它本身不改变执行流程，唯一用途是给 break 和 continue 指定作用目标，这与 Java 的 goto 有本质区别——只能从标签内部跳出或继续，不能跳进去。嵌套循环里想提前结束多层、而逻辑又无法抽成函数时，break label 比标志变量更干净；continue label 则是”跳过外层本次剩余逻辑”的唯一手段。switch 中的 break 结束的是 switch 语句本身而非循环，这个误解是大量 bug 的源头。四种循环里 break 行为一致，continue 的差异集中在”下一次迭代由谁推进”上，while 和 do...while 尤其要小心。标签能用，但它是最后手段——先想 return，再想标志变量，最后才轮到它。
