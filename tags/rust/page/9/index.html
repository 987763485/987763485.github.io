Rust 智能指针 Box 与 Rc

所有权让 Rust 在没有垃圾回收的前提下管住了内存，但它只覆盖了“一个值一个所有者”这一种形态。真实程序里还会遇到递归类型、多个持有者、共享之后仍要修改、跨线程共享等情况，这时就需要标准库提供的几类智能指针。本文按 Box、Rc、RefCell、Arc 与 Mutex 的顺序讲清它们各自解决什么问题、代价是什么，再用一张对照表和一组常见坑帮助读者做选择。本文面向已经理解所有权与借用规则的读者，示例基于 Rust 1.60 与 2021 edition。

Rust 变量、常量与可变性

Rust 的变量声明看上去和别的语言差不多，写起来却很快撞上编译器的红线：改一个值要先加 mut，同名变量却能重复声明，常量与静态量又各有各的限制。本文从 let 绑定讲起，说明 mut 的真实含义、重新赋值与遮蔽的区别，再讨论 const、static 与 'static 生命周期，最后落到作用域、解构与类型推断这些日常写法。读完之后，应当能判断一段代码该用哪种声明，也能看懂 E0384、E0308 这类报错背后的规则。示例基于 Rust 1.63 与 2021 edition。
