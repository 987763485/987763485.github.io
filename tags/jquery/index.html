jQuery 链式调用与隐式迭代原理

项目里最常见的两类 jQuery 疑问，其实答案是同一个。第一类是控制台报错：$('p').css('color').addClass('red') 抛 undefined is not a function，链子莫名其妙断了。第二类是性能：页面上只有几十个元素时一切正常，列表一渲染到 500 行，each 里的循环就明显卡手。两件事看着不相关，本质都是”链式调用靠 return this 续命，隐式迭代靠每次迭代真的去碰 DOM”这两个机制的结果。本文按这两个机制往下拆，所有结论都对着 jQuery 1.11.3 的未压缩源码逐条核过，jQuery 2.1 在这几处机制完全相同。文中所有”实测”，指在 node 里加载 jquery-1.11.3.js 配一个最小 DOM 环境跑出来的结果，量的是返回值类型、实例个数、写入次数这类机制性的事实，不涉及具体毫秒数——那个数字换台机器就变了，说它没有意义。
