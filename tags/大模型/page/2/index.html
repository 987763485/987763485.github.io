Agent 微调与领域适配

Agent 落到某个具体领域时，最常见的落差不是模型不够聪明，而是它按通用习惯说话、按通用格式发起动作。领域适配真正要做的，是把模型对齐到这个领域的动作分布上：什么样的观察应当触发什么样的决策，决策又应当落成执行器能够解析的什么格式。本文只走这条适配链路上的几个关键工位。低秩适配为什么能用少量参数改写行为，第 780 篇已经讲透了机制，本文只把它当作领域微调里最常用的那条参数高效路线来使用，不重讲它的低秩原理。

Coding Agent 设计与实现

自己写一个 Coding Agent，难的不是那个 while 循环，而是循环周围的六个决策：仓库怎么进上下文、改动用什么表示、执行反馈从哪里来、失败之后重试几次、写操作在哪里拦住、预算怎么收口。这篇只走这条工程线，不拆某个产品的内部实现，也不谈评测取数口径，目标是给出一份可以直接改的骨架和每一格的取舍理由。文中阈值均为团队约定示例，出现的数字一律是示意值，不能当实测结论。
