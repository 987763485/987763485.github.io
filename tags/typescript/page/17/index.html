NestJS 框架入门：模块与依赖注入

NestJS 在 2019 年已经发布到 6.x，很多团队把它当作从 Express 走向结构化服务端开发的第一步。初学者常把它的门槛归因于装饰器太多，真正难的是模块边界与依赖注入：同一个 service，注册在不同的模块里、用不同的 provider 写法，运行时的实例数量、可见范围和生命周期都不一样。本文以 NestJS 6.x 和 TypeScript 3.6 为基准，从启动过程一路讲到动态模块、作用域、生命周期钩子与测试，读完后你应该能为一个中等规模的服务划出清晰的模块边界，并在遇到注入报错时知道该查哪里。
