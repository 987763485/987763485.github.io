DOM 节点类型与节点关系梳理

浏览器把一份 HTML 解析成一棵树，树上每个位置都是一个节点对象，节点之间靠一组属性相连。听起来很简单，但 childNodes.length 在不同浏览器上给出不同数字、children 里莫名混进注释、innerText 读出来的文本少了半段，这些都是原生节点模型本身的行为差异，跟 jQuery 和文档碎片无关。本文只谈这一层：节点有哪些类型、关系属性各自的兼容性、以及围绕这些差异最小的一套兼容封装。增删改查的接口与 DocumentFragment 的用法在《DOM 增删改查与文档碎片 DocumentFragment》里写过，jQuery 的遍历方法另有梳理，这里不重复。
